## VPS 价格到底由什么决定

在比价之前，先理清影响 VPS 价格的几个核心因素，这样后面看套餐才不会一头雾水。

**线路是最大的价格分水岭。** 搬瓦工的线路大致分四档：美国普通线路（DC2、DC4、DC8 等，走普通 BGP）、CN2 GT（DC3 机房，半程 CN2）、CN2 GIA-E（DC6/DC9，全程 CN2 GIA 优化，电商版）、CN2 GIA（香港/东京/大阪/新加坡专用机房，三网直连）。从普通线路到 CN2 GIA，价格可以差一个数量级。

**机房位置直接影响延迟和价格。** 同样是 CN2 GIA，香港机房延迟最低但价格最高，日本次之，新加坡和大阪相对便宜一些。美国机房带宽大、流量多，但延迟一般在 150ms 以上。

**带宽和流量配额也是定价维度。** 入门套餐通常 1Gbps 带宽配 1TB 月流量，高端套餐可以做到 10Gbps 带宽配 12TB 流量。带宽越高、流量越大，价格越高。限量版套餐经常在带宽上做文章，比如 The Tokyo Plan v2 直接给到 5Gbps，这是常规套餐里很少见的。

**计费周期影响实际单价。** 搬瓦工大部分套餐支持月付、季付、半年付、年付，年付的单月均价比月付便宜不少。比如 CN2 GIA-E 入门款月付 49.99 美元，年付 169.99 美元，折算下来月均不到 14.2 美元。
